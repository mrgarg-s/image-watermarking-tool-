# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

---

# Reporting Security Issues

If you discover a security vulnerability in this software, report it responsibly.

Please include:

* Vulnerability description
* Steps to reproduce
* Screenshots or logs
* Suggested fixes (optional)

---

# Security Features

This project includes:

* AES-GCM encryption
* SHA-256 hashing
* Metadata encryption
* Full file encryption
* Password-protected verification
* Secure watermark verification

---

# Protected File Types

* PNG
* JPG
* PDF
* DOCX
* ENC encrypted files

---

# Security Recommendations

Users should:

* Use strong passwords
* Avoid sharing decryption keys
* Keep backups of encrypted files
* Verify files before sharing publicly
